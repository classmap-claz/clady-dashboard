1. 각 부서 핵심 발견사항 요약 Key Findings Summary

  • 콘텐츠(설아): M4 법적 정확도가 가장 시급. 학폭예방법 제17조 자체해결 요건 미반영. 진단 결과 문구 톤 불일관.
  • QA(하린): 퀴즈 제출 레이스 컨디션으로 Firebase 중복 기록 가능. URL 파라미터 길이 검증 미비.
  • UX(민서): 모바일 375px에서 척도 버튼 4열이 협소(텍스트 잘림). 이수증 가치가 초반에 전달되지 않아 동기부여 부족.
  • 대시보드(도윤): certCount 이중 소스(Math.max) 문제로 퍼널 전환율이 100% 초과할 수 있음.

2. 대표팀장 의견 Chief Lead Opinion

전반적으로 MVP 품질은 양호합니다(7.5/10). 그러나 파일럿 학교 배포 전에 반드시 해결할 이슈가 3개 있습니다.

첫째, M4 법적 서술은 교육심리 전문가(대표) 감수 없이 배포하면 안 됩니다. 자체해결 요건의 "피해측 명시적 동의" 누락은 실제 학부모 혼란을 초래할 수 있습니다.
둘째, 퀴즈 레이스 컨디션은 단순 버그지만 데이터 무결성에 직결됩니다. 버튼 disabled 처리 한 줄로 해결 가능하므로 즉시 수정 권장합니다.
셋째, 모바일 척도 버튼 협소 문제는 5개 페이지에 걸쳐 있어 이수율에 직접 영향을 줍니다. CSS 한 곳(style.css)만 고치면 전부 해결됩니다.

나머지 이슈(이수증 가치 전달, 프라이버시 문구 통일, 대시보드 정렬 등)는 파일럿 진행하면서 순차적으로 개선해도 무방합니다.

3. 개선 로드맵 Improvement Roadmap

  • 즉시 수정 Immediate (1일) — 퀴즈 버튼 disabled 처리, ?s= 파라미터 길이 제한, certCount 단일 소스 전환
  • 즉시 수정 Immediate (1일) — style.css 척도 버튼 모바일 2열 전환 (5개 페이지 동시 해결)
  • 단기 개선 Short-term (1주) — M4 법적 서술 대표 감수 + 수정, 진단 결과 문구 통일, 가이드 응급 프로토콜 추가
  • 단기 개선 Short-term (1주) — 이수증 가치 조기 전달(main.html 영웅 메시지), 프라이버시 문구 5페이지 통일
  • 중기 과제 Mid-term (2~4주) — 대시보드 모바일 반응형 CSS, 반 정렬 숫자순, 인쇄 페이지 구분
  • 중기 과제 Mid-term (2~4주) — 교사 역할 접근(teacher dashboard stub), 설문 시간 표기 수정
